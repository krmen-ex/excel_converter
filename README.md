# 문서 변환기

덕트 벽체 발주서를 생산작업지시서 Excel 양식으로 자동 변환하는 웹 도구.

## 사용 방법

1. 다중산출기 Excel(.xlsx) 파일을 업로드
2. 변환하기 버튼 클릭
3. 생성된 작업지시서 xlsx 다운로드

## 변환 규칙

- 입력 시트에서 `규격`/`수량` 컬럼을 자동 인식
- `1400 * 200` 형식의 규격을 폭/길이로 분리
- 동일 규격은 자동으로 수량 합산
- 길이 내림차순 정렬
- 현장명은 `발주 : ... /` 뒤 텍스트에서 추출, 날짜는 자동 제거

## 출력 양식

| 폭 | 길이 | 수량 | sheet | 차열재 |

- 같은 폭은 자동으로 세로 병합
- 14pt 굵은 글씨, 가운데 정렬, 노란색 헤더

## 기술 스택

- 단일 HTML 파일 (서버 불필요)
- [xlsx-js-style](https://github.com/gitbrent/xlsx-js-style) — Excel 읽기/쓰기 + 셀 스타일
