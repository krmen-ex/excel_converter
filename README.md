# 덕트벽체 작업지시서 변환기

다중산출기 Excel 파일을 생산 작업지시서(sheet / plate) Excel 양식으로 변환하는 웹 도구. 여러 파일을 한 번에 변환할 수 있다.

## 사용 방법

1. `index.html`을 브라우저로 연다
2. 다중산출기 Excel(.xlsx) 파일을 끌어다 놓거나 클릭해서 선택 (여러 개 가능)
3. 파일별로 현장명·저장할 파일명과 미리보기를 확인
4. 파일별 **다운로드** 또는 **전체 ZIP으로 다운로드**

## 변환 규칙

### 입력: `채움재작업지시서` 시트

- `채움재` / `내화채움판` / `수량` 머리글로 열을 자동 인식
- 같은 표가 좌우로 두 벌 있으면 화면에 보이는(숨기지 않은) 표를 읽음
- `합계` 행 전까지 읽음
- 규격 `1050 * 200`은 `길이 * 폭`
- 내화채움판 셀에 `전면: 850 * 200`과 `후면: 850 * 150`이 같이 있으면 front / back으로 나눔 (라벨이 없으면 front)
- 현장명: 다중산출기 C1의 `덕트 입상(...)/지역-업체명(발주번호)` → `지역 - 업체명(발주번호)입상`

### 출력: `작업지시서` 시트

| 폭 | 길이 | 수량 | sheet | 차열재 |
|---|---|---|---|---|

| plate | 폭 | 길이 | 수량 | sheet |
|---|---|---|---|---|

- 폭이 큰 순서, 같은 폭 안에서는 길이가 긴 순서. 같은 폭은 세로 병합
- plate는 front → back 순서, 데이터가 없는 쪽은 생략
- 채움재와 plate가 A4 한 장(28행)에 다 안 들어가면 plate는 2페이지부터 시작
- 맑은 고딕 14pt 굵게, 가운데 정렬, 테두리, 행 높이 25.5pt

## 기술 스택

- 단일 HTML 파일 (서버 불필요)
- [xlsx-js-style](https://github.com/gitbrent/xlsx-js-style) — Excel 읽기/쓰기 + 셀 스타일
- [JSZip](https://stuk.github.io/jszip/) — 여러 파일 ZIP 다운로드
